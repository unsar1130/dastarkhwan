# Karachi Dastarkhwan

Restaurant web app for Karachi Dastarkhwan, featuring **Dastarkhwan Assistant**, an AI helper for guests.

## Project Structure

```
.
├── frontend/      # Client-side code
│   ├── index.html
│   ├── styles.css
│   └── app.js
├── backend/       # Server-side code
├── data/          # Menu and restaurant data
├── prompts/       # Prompts for Dastarkhwan Assistant
└── README.md
```

## Status

Scaffolding only. No application logic yet.
